# 0006_stage4_parallel_enabled — разрешение параллельной работы зон (Этап 4)

## Назначение
Компилятор Этапа 4 (ADR-12, Артефакт 0.5 §3.4/§3.8) объединяет зоны программы
с одинаковым `parallel_group` в один параллельный шаг **только если** на
контроллере разрешена параллельная работа. Колонки для этого флага в схеме не
было — миграция добавляет её, плюс настройку значения по умолчанию из ТЗ §17.3.

## Состав
| Объект | Изменение |
|---|---|
| `controllers.parallel_enabled` | `INTEGER NOT NULL DEFAULT 0` (0 — последовательно, 1 — параллель разрешена) |
| `settings controller.parallel_enabled_default` | `"false"` — значение по умолчанию для новых контроллеров |

## Идемпотентность
- колонка добавляется только при отсутствии (`PRAGMA table_info`);
- настройка — `INSERT OR IGNORE`; повторный `upgrade()` безопасен.

## Проверка применения
```sql
PRAGMA table_info(controllers);          -- есть parallel_enabled
SELECT * FROM settings WHERE key='controller.parallel_enabled_default';
```

## Откат
Не предусмотрен (приложение читает колонку как 0 через `controller.get(...)`;
удаление колонки SQLite < 3.35 всё равно требует пересоздания таблицы).
