# 0012 — устойчивый журнал обработанных событий

Добавляет processed_events с первичным ключом controller_id/event_uid/consumer
для event, flow и schedule. Строки не удаляются ротацией событий. Инициализируется
существующими watering_events для защиты от повторной доставки после upgrade.
Добавляется индекс events(controller_id,run_id,status) для сверки фактов и плана.
Downgrade сохраняет журнал; без него повтор старого MQTT может удвоить статистику.
Данные, которые уже были удалены ДО этой миграции, нельзя достоверно восстановить
в журнале: их UID отсутствуют. Принятие backlog старой прошивки проверять отдельно.
