# Состояние текущей версии

Готово к контролируемой ручной проверке: Windows-сервер, authenticated LAN MQTT,
USB-прошивка ESP32, монитор/погода, интерактивный опрос и отчёт.

Единая точка входа: START_HERE_WINDOWS.md. Подробная подготовка: WINDOWS_SETUP.md.

Ограничения:
- Нет signed OTA, rollback и аппаратной приёмки. Прошивка только USB.
- Параллельный полив на физической плате запрещён.
- Новое расписание при занятом контроллере может быть отклонено: повторить после idle.
- Сохранность событий при произвольном отключении питания требует полевой проверки;
  broker PUBACK не равен подтверждению записи сервером.
- DS3231/физическая failsafe-кнопка не реализованы; boot/reset/OE/полярность требует стенда.
- Мастер не измеряет физическое состояние клапана: оператор подтверждает наблюдения.
- Windows CI не имеет реальной USB-платы. Completed отчёт не означает production ready.

Исторические результаты аудитов/планы удалены из активной документации; доступны
в Git и WorkBook. ТЗ и ADR сохранены для понимания требований и решений.
