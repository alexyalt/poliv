# Проверка завершения аудита 8.S

Перед обновлением сделать backup; для рабочей системы сначала независимый data root.
Основной код и проверки не удаляют runtime. Python 3.13, requirements.lock.

1. `python -m pip install -r requirements.lock`; `python -m pip check`.
2. `python -m pytest server/tests -q --disable-warnings --tb=short`.
   Все БД тестов изолированы. При многократных локальных запусках следите за местом
   временного диска, при необходимости задайте TMPDIR отдельным тестовым каталогом.
3. Установить optional Playwright 1.64.1 и Chromium с системными зависимостями;
   `python -m server.tools.browser_smoke` проверяет день/7 дней/раскрытие и missed-tab.
4. Установить Mosquitto; `python -m server.tools.mqtt_smoke`. Скрипт сам поднимает
   временный broker только на 127.0.0.1, проверяет ACK/retry/stop/replay и останавливает
   все процессы в finally. Рабочие config/broker/ESP32 не используются.
5. Проверить workflow audit-checks на SHA обновления: все jobs tests/browser/mqtt
   успешны; ручной workflow_dispatch доступен. Workflow не разворачивает приложение.
6. Перед реальной водой отдельно проверить ESP32, безопасные реле boot/reset,
   питание, MQTT ACL/TLS и reverse proxy. Зелёные проверки выше этого не доказывают.

Перенос: остановить приложение, `python -m server.tools.prepare_runtime --destination
/absolute/outside/checkout`, проверить ready=true, external_files, restore копии.
Настроить POLIV_DATA_ROOT до запуска. Удаление старого runtime из Git — только после
этого. При откате не запускать старый небезопасный append writer над v2 архивами.
