# ADR-20 — ESP32 runtime и границы аппаратной приёмки

Дата: 28.10.2026. Статус: реализовано в feature/stage10-esp32, требует стенда.

Доменный Executor и decoder/canonical JSON компилируются на native и ESP32.
HAL выбирает одну зону; water с несколькими active_zones отклоняется.
Серверный parallel_enabled для аппаратного контроллера необходимо выключить.

Длительность ограничена 3600 сек/шаг. Настенный clock выбирает due run,
монотонный clock отсчитывает время. Независимый esp_timer закрывает реле
по сроку даже во время блокировки основного цикла; task watchdog — 5 сек.
Это программная защита. Поведение 74HC595 на reset/boot и необходимость OE
должны быть проверены физически, прошивка не гарантирует состояние цепи до setup.

LittleFS: atomic rename + CRC32, без форматирования при ошибке.
Курсор пишется до открытия и каждые 5 секунд активной работы; marker done до
следующего запуска. Начальное apply при boot не пишет поверх сохранённого курсора.
Сохранённый fault и pause — NVS. Default power loss policy — skip всего активного
run. Опциональный resume может повторить до 5 секунд с последнего checkpoint;
повторные отключения требуют оценки допустимости на стенде.

События сохраняются до открытия и после закрытия; очередь 64 сообщения,
QoS1 PUBACK позволяет убрать сообщение. UID сохраняется при повторной доставке.
Это подтверждение брокера, не транзакционное подтверждение сервера. Публикации
сохраняются в брокере согласно его настройкам persistence. Авария между событием
и cursor checkpoint может дать повтор факта после power cut; стендовая проверка
и протокол server ACK/outbox остаются задачей дальнейшего усиления.

Hash сверяется SHA-256 отсортированного canonical JSON. schedule_version
нормализуется в 0: существующий сервер хеширует до persist_schedule; generated_ts,
schedule_hash и run_id исключаются. Подпись пакета и защищённое OTA — этап 11.

Новая версия во время активного/приостановленного run отклоняется, её требуется
повторно отправить после завершения. Это консервативное отклонение от поведения
эмулятора; атомарный pending schedule и immediate replacement не реализованы.

По умолчанию OUTPUTS_VERIFIED=false: service, schedule хранится, автоматические
и ручные открытия запрещены. Пин-карта и активный уровень подтверждаются без воды.
Реальная плата, USB, расходомер и broker ESP32 здесь недоступны. DS3231, кнопка
failsafe, OTA загрузчик/rollback/backup и provisioning не приняты в этой сессии.
